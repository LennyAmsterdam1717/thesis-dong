# Selection process - title/abstract screening

Records retrieved from arXiv (n = 275), OpenAlex (n = 513), OpenAlex citation chasing (backward) (n = 23), OpenAlex citation chasing (forward) (n = 42) were combined and de-duplicated with the sr-screener skill (version 1.0.0) of the open-source Academic Research Skills suite (https://github.com/Imbad0202/academic-research-skills), running in Claude Code, which matches PMIDs, DOIs and normalised titles with publication year (plus or minus one year); 184 duplicates were removed, leaving 669 unique records. Titles and abstracts were screened against the pre-specified eligibility criteria of the review protocol. Each record was assessed independently by two AI reviewers (both Claude Sonnet 5.5 (claude-sonnet-5-5), via Claude Code subagent — confirm at run time, prompted with different expert personas) that were given the same written protocol and decision rules and did not see each other's decisions. The reviewer agents had read-only file tools and no web access; each was instructed to read only the file it was given. Disagreements between advancing (include or unclear) and excluding a record (20 records) were resolved by a third AI reviewer (Claude Sonnet 5.5 (claude-sonnet-5-5), via Claude Code subagent — confirm at run time) that re-read the record. The two reviewers agreed on advance-versus-exclude decisions for 97.0% of records (Cohen's kappa = 0.939; prevalence-adjusted bias-adjusted kappa = 0.94).
