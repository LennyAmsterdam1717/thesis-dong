# Ordinal Gates, Cardinal Bets: Matching LLM Confidence to the Financial Decision Operator

**Rayansh Singh et al. (2026)** · arXiv preprint · preprint · https://arxiv.org/abs/2609.00187
_Paraphrased note by Claude (single reviewer) from the abstract, introduction and discussion/limitations; full text checked 2026-11-20._

- **Question:** How should LLM confidence be calibrated for financial decisions?
- **Method:** Nine open-weight LLMs on FactSet news for Nasdaq-100 equities; recalibration maps vs rank-based gates and position sizing; out-of-sample evaluation.
- **Main finding:** Recalibration does not matter for rank-based gates but changes position sizing; confidence maps must be revalidated with the decision system.
- **Limitations:** Weak base classifier (no market-beating claim); possible pre-training exposure to outcomes.
- **Relevance for this thesis:** G5 (finance): calibration is only meaningful relative to the financial decision rule.
